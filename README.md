# Orbitale 4

Sintetizzatore web poliritmico a 4 tracce (Web Audio API, nessuna dipendenza).
Apri `index.html` in un browser moderno (Chrome, Firefox, Safari) e premi Play.

## Pubblicarlo online con GitHub Pages
1. Crea un repository su GitHub (es. `orbitale-4`).
2. Carica `index.html` nella radice del repository ("Add file" > "Upload files").
3. Vai in Settings > Pages, scegli "Deploy from a branch", branch `main`, cartella `/ (root)`, Salva.
4. Dopo un minuto il synth è online su `https://<tuo-utente>.github.io/orbitale-4/`.

In alternativa: trascina la cartella su Netlify Drop (app.netlify.com/drop) o pubblica su Cloudflare Pages.
Basta un hosting statico: non serve server.
